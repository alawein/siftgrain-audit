# Siftgrain Census fault suite v1

Download dataset-v1.zip locally. This card is prepared for reuse; the dataset is
not uploaded to Hugging Face. Source attribution, exact bytes and reproduction:
[README](README.md). Dev and test seeds differ; test answer keys are separate
files, not a secret held-out set. Synthetic faults and cloned epochs are labeled.
